# 安全策略 / Security Policy

## 中文

请不要在公开 issue 中发布真实 IP、密钥库、密码、存档、完整日志或其他敏感数据。仓库目前没有公布私有安全联系地址，因此不要猜测或发送到非官方地址。

对于不含敏感信息的问题，请使用 GitHub 的公开安全报告表单并提供最小复现。若漏洞必须包含敏感细节，请使用 GitHub 仓库的 **Private vulnerability reporting**（仅当仓库页面显示该功能已启用）；如果不可用，请暂缓公开细节，仅创建不含利用方法和秘密的占位 issue，请维护者启用私密报告渠道。

受支持版本：在首次正式 Release 前仅维护 `main`；发布后默认仅支持最新版本。报告应说明版本、Android API、Switch 端服务版本、影响和无敏感数据的复现步骤。

## English

Do not publish real IP addresses, keystores, passwords, saves, full logs, or other sensitive data in public issues. This project does not currently publish a private contact address; do not guess one.

Use the security issue form for non-sensitive reports. For sensitive vulnerabilities, use GitHub **Private vulnerability reporting** only when the repository UI shows it is enabled. Otherwise, withhold exploit details and secrets and open only a sanitized placeholder asking maintainers to enable a private channel.

Before the first release, only `main` is supported. Afterwards, only the latest release is supported unless stated otherwise.
